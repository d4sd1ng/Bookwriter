# Project Overview: Bookwriter

## Projektziel

Der Bookwriter ist ein strukturiertes Schreibsystem für lange Inhalte.

Er erstellt keine Social-Media-Inhalte und keine Videos.

## Enthalten

- Buchidee
- Zielgruppe
- Positionierung
- Inhaltsverzeichnis
- Kapitelplanung
- Kapitelbriefing
- Rohfassung
- Redaktion
- Quellenprüfung
- Konsistenzprüfung
- Exportvorbereitung

## Nicht enthalten

- YouTube
- LinkedIn
- Shorts
- Videoproduktion
- Social-Media-Planung
- Plattform-Scheduling

## Grundworkflow

1. Projektziel klären
2. Buchtyp festlegen
3. Zielgruppe definieren
4. Nutzenversprechen formulieren
5. Tonalität festlegen
6. Inhaltsverzeichnis erstellen
7. Kapitelziele definieren
8. Quellenbedarf prüfen
9. Kapitelbriefings erstellen
10. Kapitelrohfassungen schreiben
11. Kapitel prüfen
12. Kapitel überarbeiten
13. Gesamtstruktur prüfen
14. Konsistenz prüfen
15. Export vorbereiten

## Zieloutput pro Buchprojekt

- Arbeitstitel
- Untertitel
- Zielgruppe
- Leserproblem
- Nutzenversprechen
- Inhaltsverzeichnis
- Kapitelziele
- Kapitelbriefings
- vollständige Kapitel
- Einleitung
- Schluss
- Zusammenfassungen
- Quellenliste
- Glossar, falls nötig
- Anhänge, falls nötig
- Exportstruktur

## Qualitätsziel

Das Ergebnis muss:

- logisch aufgebaut sein
- für die Zielgruppe verständlich sein
- kapitelweise konsistent sein
- ohne unnötige Wiederholungen funktionieren
- sauber prüfbar sein
- exportfähig vorbereitet sein
