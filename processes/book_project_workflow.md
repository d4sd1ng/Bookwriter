# Book Project Workflow

## Ablauf

1. Projektziel klären
2. Buchtyp festlegen
3. Zielgruppe definieren
4. Leserproblem definieren
5. Nutzenversprechen erstellen
6. Tonalität festlegen
7. Buchkonzept prüfen
8. Inhaltsverzeichnis erstellen
9. Inhaltsverzeichnis prüfen
10. Kapitelziele definieren
11. Kapitelbriefings erstellen
12. Quellenbedarf prüfen
13. Kapitel schreiben
14. Kapitel prüfen
15. Kapitel überarbeiten
16. Dopplungen prüfen
17. Gesamtstruktur prüfen
18. Gesamtredaktion
19. Quellenprüfung
20. Export vorbereiten
21. finale Freigabe
