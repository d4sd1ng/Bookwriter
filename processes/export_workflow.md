# Export Workflow

## Ablauf

1. Gesamttextstatus prüfen
2. Inhaltsverzeichnis prüfen
3. Überschriftenhierarchie prüfen
4. Quellenanhang prüfen
5. Glossar prüfen
6. Anhänge prüfen
7. Exportformat festlegen
8. Dokumentstruktur vorbereiten
9. finale Prüfliste erstellen
10. Export freigeben

## Mögliche Exportformate

- Markdown
- DOCX
- PDF
- HTML
- E-Book-Struktur
