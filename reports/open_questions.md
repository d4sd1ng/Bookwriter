# Open Questions: Bookwriter

## Projektbasis

1. Welcher Buchtyp soll zuerst erstellt werden?
2. Welche Zielgruppe hat Priorität?
3. Welches Ergebnis soll der Leser nach dem Lesen haben?
4. Wie lang soll das Werk werden?
5. Welches Exportformat ist zuerst relevant?

## Struktur

1. Soll das Buch in Teile gegliedert werden?
2. Wie viele Kapitel sind geplant?
3. Soll jedes Kapitel eine Zusammenfassung enthalten?
4. Soll jedes Kapitel Praxisaufgaben enthalten?
5. Soll ein Glossar erstellt werden?

## Stil

1. Soll der Stil sachlich, beratend oder direkt sein?
2. Wie ausführlich sollen Beispiele sein?
3. Soll mit Du-Ansprache oder neutral geschrieben werden?
4. Wie stark darf gekürzt werden?
5. Welche Begriffe müssen einheitlich verwendet werden?

## Export

1. Soll zuerst Markdown, DOCX oder PDF entstehen?
2. Gibt es Designvorgaben?
3. Gibt es eine Formatvorlage?
4. Werden Bilder oder Grafiken benötigt?
5. Soll eine druckfähige Version vorbereitet werden?
